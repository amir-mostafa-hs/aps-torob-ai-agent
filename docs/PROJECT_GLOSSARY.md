# Project Glossary

- **Base product:** The canonical product entity and its stable attributes, separate from a specific shop’s offer.
- **Offer / product-in-store:** A recorded relationship between a product and a shop, containing seller-specific price and conditions when available.
- **Recorded price:** The value stored in the dataset. It is not automatically a live quote.
- **Price freshness:** How recently the recorded price was updated, derived only from a real timestamp.
- **Confirmed availability:** Availability that was actually confirmed by a trusted source. A dataset offer alone does not imply this.
- **Unknown:** The data does not prove either positive or negative status.
- **Seller inquiry simulation:** An in-app demo interaction based on inspected local state/data, not actual external seller contact.
- **Generative UI:** Selecting/ordering predefined UI components using validated structured data; it does not mean executing model-generated code.
- **Phase gate:** An acceptance boundary. A phase passes only when required tests and evidence exist.
- **Source dataset:** The original challenge/preprocessed data files that are treated as immutable inputs.
- **App-state database:** A separate writable store for limited-lived anonymous sessions or other operational state.
